# CommandPatternProject

Практикалық жұмыс №12

Тақырыбы: Command паттерні

Нұсқа: 4 – Графикалық редактор (Canvas)

## Мақсаты
Command паттернін Java тілінде қолдануды үйрену.

## Командалар
- DrawShape – фигура салу
- MoveShape – фигураны жылжыту
- DeleteShape – фигураны өшіру
- Undo – әрекетті болдырмау
- Redo – әрекетті қайта орындау
- MacroCommand – бірнеше команданы бірге орындау

## Технологиялар
- Java 17
- IntelliJ IDEA
